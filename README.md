# Talon

The home of Talon's projects: games, software, stories, music, 3D work, and the Talonwing community.

This is a static website built with plain HTML, CSS, and JavaScript. There is no build step, package manager, or framework to install.

## Files

- `index.html` — homepage
- `projects.html` — full project index
- `styles.css` — shared responsive design and page styles
- `script.js` — mobile navigation and small interactions
- `favicon.svg` — Talon site icon
- `games.html` — redirect to the games section of the project index

## GitHub Pages

The site is designed to run from the repository root on GitHub Pages.

1. Open the repository's **Settings**.
2. Open **Pages**.
3. Set the source to **Deploy from a branch**.
4. Choose the `main` branch and `/(root)`.
5. Save.

Once GitHub Pages finishes publishing, the site is available at:

https://captainbensword.github.io/Talon/

## Editing

Edit the HTML for page content and `styles.css` for visual changes. Project links are kept in the page markup so they are easy to update as projects get their own public pages.

The site uses system fonts and inline artwork, so it does not depend on external image hosts or font services.
